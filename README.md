# Civil Engineering Unit Converter

A beginner Python project that converts common length measurements
used in engineering and technical coursework.

## Features

- Converts between millimeters, centimeters, meters, and kilometers.
- Supports inches, feet, yards, and miles.
- Accepts unit abbreviations and common full unit names.
- Checks for unsupported units and invalid numeric input.
- Uses meters as the standard unit for conversion calculations.

## Technologies

- Python 3
- Dictionaries and functions
- User input and input validation
- Mathematical unit conversions

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   python unit_converter.py

5. Enter a measurement, its starting unit, and the target unit.

## Example

Input:

- Measurement: 10
- Starting unit: ft
- Target unit: m

Output:

    Result: 10 ft = 3.048 m

## Purpose

This project was created to practice Python programming and
explore how simple software tools can support engineering
coursework and measurement conversions.
